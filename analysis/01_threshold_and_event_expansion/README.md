# Threshold learning and event expansion

The four scripts generate the best-of-SNV ACT-REL figure, the K-means-derived cut-off figure, the K-sensitivity figure and the six-panel event-expansion figure. Every panel has its own x-axis and y-axis title.

The eight compressed input tables were recovered from the formal coding and lncRNA screening and expansion packages. They preserve the rows used in the figures while avoiding duplicate uncompressed copies.

Key provenance:

- coding best-of-SNV data: `cd_upstream_and_shared_inputs_20260720.tar.gz` in migration package 05;
- lncRNA best-of-SNV data: `lnc_best_of_snv_211_and_6268_20260716.tar.gz` in migration package 01;
- coding and lncRNA expanded events and risk-oriented direction tables: migration package 01.

The numerical K=3, K=4 and K=5 first-cut-off summary plotted by script 03 is the compact summary used in the Methods and Results; it is embedded directly in that script.
