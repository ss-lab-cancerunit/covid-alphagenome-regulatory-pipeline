# Position and cCRE models

`run_position_ccre_models.py` reads the 374-pair model table and tests genomic position, candidate cis-regulatory element class and analysis mode. It writes adjusted cell estimates, model tests, coefficients and the two-panel figure to `outputs/`.

The input table and executed analysis script were recovered from `COVID_AGPT_3_4_FINAL_MODEL_FIGURES_PACKAGE`.
